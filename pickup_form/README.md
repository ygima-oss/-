# 8月マンスリー ピックアップ 事前ヒアリングフォーム

登壇者向けの事前ヒアリングをGoogleフォームで自動生成し、回答用スプレッドシートに連携するGoogle Apps Scriptです。

## セットアップ手順

1. [Google Apps Script](https://script.google.com) で新規プロジェクトを作成
2. [`createPickupForm.gs`](./createPickupForm.gs) の内容を貼り付けて保存
3. 関数 `createPickupForm` を実行（初回は承認が必要）
4. 実行ログに出る3つのURLを確認
   - 回答用フォームURL（発表者に共有）
   - 編集用URL（設問の修正）
   - 回答スプレッドシートURL
5. 「回答用フォームURL」を登壇者に共有

送信された回答は、連携スプレッドシートに自動で1行ずつ蓄積されます。

## フォーム構成

| ページ | 内容 |
| --- | --- |
| 記入者情報 | 氏名・所属店舗・トレーナー歴 |
| セクション1 | あなたにとっての「かかりつけ」（Q1–Q2） |
| セクション2 | エピソードの主役を決める（Q3–Q5） |
| セクション3 | あなたの関わり方（Q6–Q8） |
| セクション4 | 変化と、エピソードの核（Q9–Q11） |
| セクション5 | 3分トークの組み立て（Q12） |

1. まず押さえる基礎指標

CPA（Cost Per Acquisition）＝ 獲得単価

1件のコンバージョン（体験申込・入会）を得るのにかかった広告費。

CPA = 広告費合計 ÷ CV（コンバージョン）数

例：広告費 ¥100万、体験申込 100件 → CPA = ¥10,000

CPO（Cost Per Order）＝ 入会獲得単価

1件の入会を得るのにかかったコスト。

CPO = CPA ÷ 入会率

例：CPA ¥10,000、入会率 50% → CPO = ¥20,000

CVR（Conversion Rate）＝ コンバージョン率

LPを訪れたユーザーのうち、実際に申込んだ割合。

CVR = CV数 ÷ LP訪問者数 × 100（%）

THE PERSONの現状：CVR < 1%（目標：約2%）

CPC（Cost Per Click）＝ クリック単価

CPC = 広告費 ÷ クリック数

CTR（Click Through Rate）＝ クリック率

CTR = クリック数 ÷ インプレッション数 × 100（%）

広告比率

全体の入会数のうち広告経由が占める割合。THE PERSONの目標：広告比率 50%（現状ほぼ広告依存 → 半分は非広告で獲得）

指標のつながり：CPA = CPC ÷ CVR
CPAを下げるには「CPCを下げる」か「CVRを上げる」。
CVRが1% → 2%になれば、広告費そのままでCPAは半減する。
例：CPC ¥500、CVR 1% → CPA = ¥50,000（高い）
　　CPC ¥500、CVR 2% → CPA = ¥25,000（CVR2倍でCPA半減）

ボトルネックの所在

入会率は達成済み（50%）。ボトルネックは「体験申込を集める効率（CPA）」にある。
  • ボトルネック①：CVR < 1% ── 100人がLPに来ても1人しか申し込まない。CVR 2%になればCPAはほぼ半減
  • ボトルネック②：店舗間CPAばらつきが最大3倍 ── 商圏差により全店一律の広告運用では非効率が混在

なぜ広告比率50%を目標にするのか

全体CPA = 広告CPA × 広告比率 ＋ 非広告CPA × 非広告比率
例：広告CPA ¥20,000（広告比率100%）→ 全体CPA = ¥20,000
　　広告CPA ¥20,000（50%）＋ 紹介CPA ¥2,000（50%）→ 全体CPA = ¥11,000
　　→ 広告CPAが同じでも、非広告チャネルを育てるだけで全体CPAが大幅改善

3. CPAを下げる3つの構造

【構造A】CVRを上げる（最大レバー）
  • LPのデザイン・文言・構成を改善
  • ターゲット別LP（女性向け・ミドルシニア向け）を作成
  • フォームの入力項目を減らす
  • ページの表示速度を上げる

→ CVR 1% → 2% でCPAは約半減（費用そのままで成果2倍）

【構造B】CPCを下げる（広告効率改善）
  • 不要なキーワード・エリアを除外して無駄クリックを減らす
  • 入札戦略を見直す
  • 広告文・クリエイティブを改善してCTRを上げる
  • Meta/Googleの予算配分を最適化する

→ 同じ予算でより多くのクリックを獲得

【構造C】非広告チャネルを育てる（中長期）
  • SEO：記事コンテンツで検索流入を増やす（広告費ゼロ）
  • アフィリエイト：成果報酬型なので固定コストゼロ
  • リファラル（紹介）：インセンティブ原価のみで獲得
  • オフライン：ポスティング・駅前看板で商圏内認知を上げる

→ 広告比率を下げることで全体（ブレンド）CPAを構造的に低減

4. 重点施策 ① 広告運用の最適化

(a) 運用の最適化

エリアターゲティング

  • 店舗から徒歩圏（約1〜2km）に絞って配信
  • 商圏外への配信は除外設定する
  • 協業先から居住エリアデータをもらえれば精度アップ

キーワード管理（Google広告）

  • 効果の低いキーワードを定期的に棚卸し
  • 除外キーワードを追加（競合名・無関係ワード）
  • 広告文を定期刷新（月1回以上）

配信面の精査（Meta広告）

  • Instagram Stories、Facebook フィードなど、CPAが高い配信面を除外
  • 年齢・性別・興味関心のターゲティングを見直す

店舗別の配信ON/OFFルール

  • 許容CPAを超えた店舗は出稿を抑制 or 停止
  • 好調店には予算を増やして最大化

(b) 予算の最適化

  • Meta / Google の配分を実績CPAで判断（効率の良い方に寄せる）
  • 店舗ごとに予算上限を設定（不調店の垂れ流しを防ぐ）
  • 週次でCPA確認 → 月内に予算配分を調整するサイクルを作る

(c) クリエイティブの改善

訴求軸ターゲットフォーマット
リカバリー（疲れ・体型戻し）30〜40代静止画・動画
女性向け（美体型・産後）20〜30代女性リール・Stories
ミドルシニア（健康維持・体力）40〜50代静止画・動画
  • 月次で新しいバリエーションを一定数投入（マンネリ防止）
  • 勝ちクリエイティブを横展開（他店舗でも使う）
  • デザイナーとのフロー（Slack連携）を高速化
期待効果：媒体CPA ¥15,675 → ¥10,000（▲36%）・店舗間CPAのばらつきを縮小

5. 重点施策 ② LPO（ランディングページ最適化）

CVR < 1% ＝ LPに来た99%以上が申込まずに離脱している。
CVR 1% → 2% になれば広告費ゼロで体験申込数2倍 ＝ CPA半分。

LP改善の優先順位

【優先度 高】ファーストビュー
  • ターゲットが「自分向けだ」と思えるビジュアル・コピー
  • ベネフィットが瞬時に伝わるか（何が得られるか）
  • CTAボタンが目立つか
【優先度 高】フォーム最適化
  • 入力項目は最小限（名前・電話番号・希望日時のみが理想）
  • ボタンラベル例：「申し込む」→「今すぐ無料体験を予約する」
  • スマホで入力しやすいか（入力欄の大きさ・キーボードの種類）
【優先度 中】ターゲット別LPの出し分け
  • 共通LP・女性向けLP・40〜50代向けLP を広告ターゲティングに合わせて表示
  • ターゲットに刺さるLPを見せることでCVRが上がる
【優先度 中】ページ表示速度
  • 3秒以上かかると離脱率急上昇（1秒遅くなるごとにCVR約7%低下）
  • 画像最適化（WebP形式・圧縮）、不要タグ整理、遅延読み込み設定

SquadBeyond（LP量産ツール）の活用

  • 1つのLPから複数バリエーションを素早く生成、A/Bテストを高速化
  • まず1店舗・2〜3ヶ月のトライアルで効果検証
  • 評価基準：CVR改善率、CPA改善率

CVR積み上げのロジック

施策CVR改善寄与
ファーストビュー改善+10%
フォーム最適化+15%
ターゲット別LP+10%
ページ速度改善+5〜10%
合計CVR 約1% → 2% を目指す

6. 重点施策 ③ 中長期チャネル（SEO・アフィリエイト・オフライン）

SEO（検索エンジン最適化）

THE PERSONの強み：ドメインレーティング（DR）が高い ＝ Googleからの信頼度が高い。良質な記事を書けばランクアップしやすい。
  • 地域ロングテールキーワード記事：「パーソナルトレーニング 〇〇駅」など
  • 悩み系記事：「産後ダイエット おすすめ」「50代 筋トレ 効果」など
  • サイト構造の整理（内部リンク、タイトル・メタ情報の最適化）
  • AI検索（ChatGPT・Perplexity）対策も兼ねたコンテンツ設計

SEOは成果が出るまで3〜6ヶ月かかる。今すぐ始めないと次期に間に合わない。

アフィリエイト

比較メディアへの掲載で、体験申込・入会があった場合にのみ報酬を払う成果報酬型。固定費ゼロ。

  • ASP業者と契約・連携
  • 比較記事への掲載営業を強化
  • 既存アフィリエイトの是正対応（誤情報確認）

Googleマップ（MEO）

  • 「パーソナルジム 〇〇」検索で上位表示 → 来店意欲の高い近隣ユーザーにリーチ
  • Googleビジネスプロフィールを最新化（写真・営業時間・電話番号）
  • 口コミへの丁寧な返信（評価数・評価がランクに影響）

オフライン施策（認知・商圏獲得）

来店動機1位「自宅から近い」 → 商圏（徒歩圏）への直接リーチが最も有効

7. 重点施策 ④ リファラル（紹介）施策
── 紹介を増やす実装プレイブック

獲得コスト ≒ インセンティブ原価のみ（¥2,000〜¥5,000程度）
広告CPA ¥17,580 と比べて圧倒的に低コスト。
会員満足度 ★4.9 を紹介行動に転換できていない ＝ 伸びしろが大きい。

大前提：「満足 ≠ 紹介行動」

★4.9でも紹介が少ない理由は、3つの欠如にある。
  1. きっかけがない → 依頼されていない
  2. 手間がかかる → 紹介のハードルが高い
  3. 動機が弱い → メリット設計ができていない
この3つを同時に解消することが、紹介を増やす構造的な打ち手になる。

欠如① きっかけを作る（依頼と仕組み）

人は「紹介して」と言われない限り動かない。依頼する仕組みを作ることが最優先。

トレーナーからの声かけをルール化

  • タイミング 入会3ヶ月後（満足度がピークになりやすい時期）
  • 逃さない 「目標体重達成」「体脂肪率低下」「腰痛改善」など成果が出た瞬間 ＝ 紹介が最も生まれやすい瞬間
  • この場で紹介カードを渡す / アプリの紹介機能を案内する

声かけスクリプト（例）

「最近すごくいい感じですね！
もし周りでジム始めたい方いたら、ぜひ紹介してください。
ご紹介いただいた方にも特典をご用意しています。
このカード（orリンク）を渡してもらえれば大丈夫ですよ」

→ 全店で統一したスクリプトを使い、声かけの属人化を防ぐ

紹介キャンペーン期間の設定

  • 「今月紹介すると特典2倍」など期間限定で行動を促す
  • 新店オープン・記念月・閑散期などのタイミングに合わせると効果的

欠如② 手間をゼロにする（紹介導線の整備）

「友達に説明して…連絡して…」が面倒で行動しない。紹介のステップを最大限シンプルにすることが鍵。

会員アプリ / LINE公式アカウント

  • 紹介リンク・QRコードを1タップで友人に送信できる
  • LINE公式の「友だち紹介」機能を活用するのが実装コスト最小
  • 申込が完了すると紹介者に自動で通知・特典が付与される仕組み

被紹介者が説明不要な状態にする

  • リンクを送るだけで「初回無料体験ができる」ことが分かるLPに着地させる
  • 「〇〇さんからご紹介いただいた方へ」という動的な訴求を入れるとCVRが上がる

店頭の紹介カード（アナログ施策）

  • デジタルが苦手なシニア・ミドル層にはカードが有効
  • 体験後・入会後に毎回渡すルールにする（渡し漏れをなくす）
  • QRコードを載せて、紙でもデジタルでも申し込めるようにする

家族・パートナー割の設計

  • 「一緒に通う」は最も成約しやすい紹介パターン
  • 既存会員の満足度が高い業態ほど「ファミリープラン」は効きやすい

欠如③ 動機を設計する（インセンティブ）

基本構造：紹介者・被紹介者の双方に特典
紹介者だけへの特典では「友達を売る」感覚が生まれる。双方に特典があることで「友達にもいいことがある」と行動しやすくなる。
対象特典例金銭的価値
紹介者月会費 ¥3,000 割引（1ヶ月）
体験チケット1枚
セッション1回サービス		¥3,000〜¥5,000相当
被紹介者初回体験無料
入会金無料
入会月の月会費割引		¥3,000〜¥20,000相当
景品表示法により提供できる景品・割引額には上限がある。一般懸賞：取引額の20倍以内かつ上限10万円が目安。実施前に必ず法務確認を行う。

成果報告・ビジュアルを活かした自然な紹介

  • ビフォーアフター写真（本人同意のもと）をSNSで投稿 → 見た友人から「どこのジム？」という流れ
  • Instagramストーリーズでのシェアを促す（投稿テンプレートを会員に提供すると行動しやすい）

かかりつけトレーナー起点の紹介促進（THE PERSONの最大の武器）

THE PERSONの最大の資産は「★4.9 × かかりつけトレーナーの信頼関係」。
広告では絶対に作れない「人からの推奨」が眠っている状態。

声かけのタイミング設計

タイミング声かけ内容
入会直後「もし知人・家族で興味ある方いたら紹介カードお渡しします」
入会3ヶ月後「最近すごく変化が出てきましたね。ぜひ周りにも紹介を」
成果達成時「達成おめでとうございます！ぜひ友人にも教えてあげてください」
更新時「継続ありがとうございます。ご紹介キャンペーン中です」

トレーナーへのインセンティブ設計

  • 紹介を生んだトレーナーを社内で評価・表彰する仕組みを作る
  • 紹介件数を評価指標の1つに組み込む（モチベーション向上）
  • 現場が自発的に動く仕組みにすることが、紹介数の安定増加につながる

仕組み化で継続的に効かせる追加アイデア

施策狙い
紹介キャンペーン期間の設定「今月特典2倍」で行動を一気に促す
成果報告のSNS投稿促進ビフォーアフター投稿 → 自然な紹介導線
家族・パートナー割「一緒に通う」は最も成約しやすい紹介
トレーナーへのインセンティブ現場が自発的に動く仕組み化
紹介率のKPI化会員1人あたり紹介率を月次で可視化・店舗別比較

計測指標

  • 紹介経由の入会数（月次）
  • 会員1人あたりの紹介率（紹介数 ÷ 総会員数）
  • 紹介経由CPA（≒ インセンティブ原価 ÷ 紹介入会数）
  • 紹介導線別の申込数（アプリ / LINE / 店頭カード）

9. KPIの見方・モニタリング方法

週次で見る指標（広告担当）

  • 媒体CPA（Meta・Google 各管理画面）
  • CVR（GA4）：LP訪問 → 体験申込
  • CTR：広告のクリック率
  • 予算消化状況：各店舗の予算残と想定CPAのズレ確認

月次で見る指標（チーム全体）

  • 全体CPA / CPO（媒体 + 非広告チャネル含む実態値）
  • チャネル別CV数（広告 / SEO / アフィリエイト / 紹介 / その他）
  • 広告比率（= 広告CV ÷ 全体CV）
  • 店舗別CPA の比較（ばらつきの確認）
  • 紹介経由入会数・会員1人あたり紹介率

CPAが急に悪化したときのチェックリスト

  1. クリエイティブの疲弊（同じ広告を出し続けてCTRが下落）
  2. 競合の参入（入札単価が上昇しCPCが上がった）
  3. LPの問題（ページ速度低下・フォームエラー）
  4. 季節性（年末年始・夏季は検討層が減る時期がある）
  5. トラッキングのズレ（タグの計測漏れ）

CVRが低い店舗のチェックリスト

  1. LPがその店舗の商圏ターゲットに合っているか
  2. ファーストビューのビジュアルがターゲット層に合っているか
  3. フォームの完了率（開いたが送信しない離脱がないか）
  4. ページ表示速度（GTmetrix / PageSpeed Insights で計測）

まとめ：CPA低減の優先順位

  • 優先度1（最大インパクト）：LPO → CVRを1%→2%に上げる ＝ CPA約半減
  • 優先度2（即効性あり）　：広告運用の精度向上 ＝ 無駄なコストを削る
  • 優先度3（中長期・構造）：非広告チャネル育成 ＝ 広告依存を下げる
  • 補完施策（低コスト）　：リファラル強化 ＝ ブレンドCPAを押し下げる

「CVRを上げながら、広告の無駄を省き、非広告チャネルを育てる」
この3つが同時に進むと、CPA目標（¥10,000）が視野に入る。

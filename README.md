# 店舗資料リポジトリ

店舗ごと・テーマごとに資料を整理したリポジトリです。

## フォルダ構成

```
.
├── himonya/                # 碑文谷店（THE PERSON 碑文谷）
│   └── nakatomi/           # 中富さん関連資料
└── mizonokuchi/            # 溝の口店
```

| フォルダ | 内容 |
|---|---|
| [`himonya/`](./himonya/) | 碑文谷店の資料（配下に中富さん関連 `nakatomi/`） |
| [`mizonokuchi/`](./mizonokuchi/) | 溝の口店の資料（施設利用マニュアルなど） |

## 命名規則

- ファイル名は `YYYYMMDD_内容.html` 形式（日付は資料の更新日）
- 日付プレフィックスにより、どのOS・ツールでも時系列で自動ソートされます
